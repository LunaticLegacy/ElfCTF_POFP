# Meta Documents

这一区域保存项目管理、总结和研究报告类文档。它们不是主知识条目，不应作为 Agent 的首轮检索目标。

## 用途

- 记录阶段性总结、完成报告和研究报告
- 保存已经从主知识库分离出来的项目元信息
- 作为维护历史，不参与主检索索引

## 说明

- 这些文档保留原始研究和迁移记录。
- 若要寻找可复用知识，请优先看 `../README.md`、`../index.md` 和专题目录。
- 若要核对迁移或研究历史，再回到这里。
