# Case Studies

## 安全边界

本目录只用于 CTF、授权分析、样本研究和教学。不要把案例步骤迁移到未授权目标、真实入侵、持久化或规避检测场景。

## 目录导航

- [已审核案例](./reviewed/README.md)
- [草稿案例](./drafts/README.md)

## 使用建议

- 先看 `reviewed/`，再看 `drafts/`
- 已审核案例更适合人和 Agent 直接检索
- 草稿案例适合追踪任务元信息和待补线索

## 案例写作规范

每个案例尽量包含：

1. 来源
2. 结论摘要
3. 关键证据
4. 可复用知识点
5. 误判与返工
6. 相关专题页
7. 自动化机会
