# Reviewed Case Studies

这里存放已经整理为正式知识资产的案例。它们通常有相对完整的分析链路、结论摘要和可复用经验。

## 适用范围

- 已经完成人工审核的案例
- 结构完整、可作为参考路径的题解沉淀
- 适合人类阅读，也适合 Agent 先读

## 收录原则

- 先沉淀可复用的判断过程，再保留关键证据
- 通过专题页建立回链，而不是只保留最终答案
- 若案例仍有明显缺口，应降级到 `../drafts/`
